# Excel Employee Data Cleaning and Analysis

## Project Overview
This project demonstrates employee data cleaning, transformation and analysis using Microsoft Excel, including formulas, data organization and summary calculations.

## Objectives
- Analyze overall sales performance.
- Monitor revenue, cost, and profit.
- Understand customer purchasing patterns.
- Identify monthly sales trends.
- Present key performance indicators through an interactive dashboard.

## Tools and Techniques
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Data cleaning and organization
- Interactive slicers
- Dashboard design and visualization

## Key Analysis
- Total revenue
- Cost of goods sold
- Total profit
- Customer analysis
- Monthly sales performance

## Project Outcome
Developed an interactive sales dashboard that presents key business metrics and makes it easier to explore sales performance.
