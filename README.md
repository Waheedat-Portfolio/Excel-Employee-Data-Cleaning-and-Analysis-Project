# Excel Employee Data Cleaning and Analysis Project

## Project Overview
This project demonstrates my practical Excel skills in employee data cleaning, text manipulation, and data analysis using Microsoft Excel.

## Tools Used
- Microsoft Excel

## Tasks Performed

### 1. Data Formatting
- Bolded column headers and applied background color.
- Added borders to the employee data table.
- Formatted monthly salaries as currency.

### 2. Text Functions
- Extracted first and last names from full names.
- Generated employee email addresses.
- Calculated full-name character lengths.
- Converted department names to uppercase, lowercase, and proper case.
- Used TRIM to remove extra spaces.

### 3. Aggregate Functions
- Used SUM, AVERAGE, and COUNTA.
- Applied SUMIF and AVERAGEIF.
- Used SUMIFS and AVERAGEIFS for multiple criteria.
- Applied COUNTIFS and MAXIFS for conditional analysis.
